# DESIGN: ICONOGRAPHY
## STYLE
Simple, clear line icons. Consistent weight. Recognizable to non-technical, industry users.

## KEY ICONS (by domain)
Fabric (roll/meter), Trim (button/zip), Craft (hand/needle), Job work (machine/process), QC (checkmark/magnifier), Order (box), Escrow (shield/lock), QR (scan), Verification (badge/tier), Chat (bubble), T&A (calendar), Money (rupee).

## RULES
Meaning over decoration. Consistent metaphors across the platform. Pair icons with labels where the audience may not recognize the symbol alone.
