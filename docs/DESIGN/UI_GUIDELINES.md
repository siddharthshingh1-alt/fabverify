# DESIGN: UI_GUIDELINES
## LAYOUT
- Main platform: left panel nav + content area (desktop-first).
- FabChat: mobile 3-tab (Chats/Orders/Scan).
- Enterprise: department nav; CEO money-first landing.

## INTERACTION
- Dashboards surface what needs attention now.
- One primary action per screen where possible.
- Modals for focused tasks (portal-rendered).
- Progressive disclosure: beginners guided, experts unencumbered (Principle 5).

## CONTENT
- Plain, dignified language; local language where relevant.
- Errors explain + offer a path, never blame.
- Celebrate real wins sincerely ("you earned the largest share this month").

## ACCESSIBILITY
- Works on cheap phones, bright light, low literacy.
- Voice input where typing is a barrier (FabVoice).
- Photo-based find for inventory.
