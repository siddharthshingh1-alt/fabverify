# PRODUCT: USER_FLOWS
> The key step-by-step paths through the product.

## ONBOARDING
Phone → OTP → profile → user-type selection → type-specific dashboard. (Enterprise adds position selection.)

## VERIFICATION
Country selector → identity check → business check → tier → (Silver/Gold) admin review → status → gates escrow.

## BUYER → ORDER
Discover (filters + trust signals) → enquiry/sample brief → sampling (proto/fit/PP) → digital approval → bulk order → escrow fund → QR-verified milestones → QC → dispatch → receipt scan → final release → reorder.

## MANUFACTURER
Onboard → appear in discovery → receive enquiry/brief → accept order → update milestones (photo/QR) → get paid on proof (FabFloat).

## HIRING (FabTalent)
Search by type+specialisation → view profile → hire → escrow → gig-adaptive workspace → delegated approval-gated access → deliver → payment → portfolio/FabScore update.

## FABRIC MILL
List fabric → buyer swatch request → dispatch (fee) → lab dip approval → dye lots + shade bands → meter-based order → dispatch → (reorder matches COL-).

## JOB WORKER
Receive parent-linked job → shift-start photo → process → shift-end/overtime photos (per-style tag) → return + reconcile → QR verify vs capacity → paid.

## ARTISAN
Receive direct order (fair price shown vs middleman) → materials on credit → craft (honest timeline) → authenticity proof → escrow release → "you earned ₹X directly."
