# BUSINESS: SALES_PROCESS
## MARKETPLACE (self-serve + light touch)
Manufacturers/mills/artisans onboard + verify; brands sign up + transact. Low-touch, product-led.

## ENTERPRISE (high touch — the profit engine)
1. Warm intro (Fabindia relationship / referrals).
2. Show the CEO glance-view + one-place operation (fabric sourcing → accounts).
3. Pilot: onboard their existing vendors (who then use FabVerify).
4. Land subscription; expand seats/departments.
5. Retain via depth (they run everything here; switching cost is high).

## KEY
Enterprise sales is relationship + demonstrated ROI (fewer meetings, full visibility, verified vendors). The Fabindia relationship shortcuts the first, hardest sale.
