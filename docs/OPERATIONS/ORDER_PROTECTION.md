# OPERATIONS: ORDER_PROTECTION
> The end-to-end protection wrapped around every order.

## THE THREE LAYERS (Brand vision)
1. Before: verified discovery, honest costing, unit-economics guard, low-MOQ matching, guided journey (no skipping sampling).
2. During: escrow, QR-verified milestones, tracking, per-gig expert hiring, FabChat.
3. After: FabPay Later, cash-flow forecast, consistent reorder, dead-stock recovery.

## HOW PROTECTION WORKS OPERATIONALLY
Order → escrow funds held (partner) → each milestone QR-verified → release on proof → QC before dispatch → buyer receipt scan → final release → close. Anomalies hold payment + notify. Disputes resolved by the verified chain.

## RULES
Money follows proof (M2). Verified reality drives releases. Honest workers never false-alarmed (V4). Buyer protected from ghosting; maker protected from non-payment.
