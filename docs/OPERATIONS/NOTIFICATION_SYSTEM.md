# OPERATIONS: NOTIFICATION_SYSTEM
> Reaching users at the right moment.

## CHANNELS
WhatsApp (primary — the doorbell), in-app notification centre, (email later).

## EVENTS
New order/enquiry/brief, approval needed, milestone verified, payment released, delay, anomaly flag, credit KFS ready, verification approved.

## RULES
Notify on real events only (no spam). Anomaly notifications only for genuinely impossible discrepancies (V5) → to buyer + FabVerify team. Credit-related contact within 8am–7pm. Templated, localised.
