# MODULE: IDENTITY_AND_TRUST
> The foundation everything stands on: verification + FabScore + trust tiers.

## PURPOSE
Turn a "trust me" industry into a verified, proof-based one. Every badge, score, and escrow release traces to real verification.

## WHAT IT DOES
- Government-DB verification (India: Aadhaar/DigiLocker, PAN, GST, Udyam/MSME, CIN/MCA; Global: passport + selfie + country registration).
- Cross-links all IDs to one entity (catches impersonation).
- Tiers: Bronze (identity, instant) → Silver (business, 2–3d) → Gold (physical audit, EU-ready).
- FabScore: portable reputation from verified behavior; lowers honest credit cost.
- Verification gates escrow eligibility (M5, M7).

## STATUS
Wizard screens 🟡 · status tracking + tier sync ✅ · real gov-DB APIs 🔴 · FabScore algorithm 🔴 · admin approval panel 🔴.

## KEY RULES
Real verification never self-declaration (M6). Store status, never raw IDs. Consent-based, encrypted, India-localised. Bronze auto; Silver/Gold pending review.

## CONNECTS TO
Escrow (gates payouts) · Credit (FabScore→APR) · Discovery (badges) · QR (scanner identity) · Enterprise (vendor KYC).

## DATA
