# MODULE: MERCHANDISING (T&A)
> The order conductor's toolkit — the living Time & Action calendar.

## PURPOSE
Give the merchandiser (freelance or enterprise) the one tool their life revolves around: a living T&A that auto-tracks every milestone and surfaces delays and pending approvals.

## WHAT IT DOES
- Living T&A calendar (planned/actual dates, delay days, responsible party, status; auto-calculates delays; auto-updates from scans/approvals).
- Approval-chasing tracker (who it waits on, days pending, one-tap reminder).
- Multi-order health dashboard; auto-generated daily to-do.
- Costing + negotiation via FabPricingEngine.

## STATUS
All 🔴 (design-locked). See USER_TYPES.md → Merchandiser.

## KEY RULES
T&A is the home screen. Gig-adaptive (one order / season / sourcing-only). Orchestrates LD/SMP/TP/FAB/TRIM/QC/QR under TNA-[OrderNo].
