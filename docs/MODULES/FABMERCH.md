# MODULE: FABMERCH (FabTalent Marketplace)
> Hire any specialist for any need — the universal talent marketplace.

## PURPOSE
Let anyone (brand, mill, manufacturer, enterprise, solo owner) hire the exact specialist they need per-gig — so a solo brand operates like a big one.

## WHAT IT DOES
- Universal specialist search: Designer (apparel/print/woven/knit/embroidery/colorist/surface), QC (fabric-4point/in-line/final-AQL/pre-production/lab), Master (by category), Merchandiser (by stage).
- FabTalent profiles + skill-verified badges + portfolio + rates + availability + reviews + repeat-hire rate.
- Hire → escrow → gig-adaptive workspace → delegated (approval-gated) access → deliver → payment → portfolio/FabScore update.

## STATUS
Hire-flow + profiles 🟡 (screens only) · portfolio auto-build 🔴 · gig-adaptive workspace 🔴 · delegated access 🔴.

## KEY RULES
Universal marketplace (P3) — any user hires any specialist. Freelancer experience adapts to the gig (P2). Delegated access is scoped + approval-gated; money never delegable (P10).

## CONNECTS TO
Company Profiles · Identity (skill-verify) · Payments (escrow) · every hiring user type · Documents (deliverables).

## DATA
Planned fabtalent_profiles (TAL-), gig/workspace + delegation permission tables.
