# MODULE: NOTIFICATIONS
> The doorbell — bring users back at the right moment.

## PURPOSE
Reach users where they are (WhatsApp/in-app) about the things that matter: new orders, approvals needed, payments released, delays, anomalies.

## WHAT IT DOES
- WhatsApp notifications (order events, approvals, payments, delays).
- In-app notification centre.
- Anomaly alerts to buyer + FabVerify team (from the verification engine).
- Approval-chasing reminders (merchandiser one-tap).

## STATUS
All 🔴. WhatsApp notifications are a Phase-A priority (users don't return without the doorbell).

## KEY RULES
Notify on real events, not spam. Anomaly notifications only for genuinely impossible discrepancies (V5). Respect quiet hours for anything credit-related (8am–7pm). Templated, localised messages.

## CONNECTS TO
Orders · Payments · Traceability (anomalies) · Merchandising (reminders) · Admin.

## DATA
Planned notifications table; WhatsApp integration via partner API.
