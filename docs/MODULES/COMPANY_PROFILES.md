# MODULE: COMPANY_PROFILES
> Every participant's profile/storefront, type-adaptive.

## PURPOSE
Give each user type a profile that presents them accurately and builds trust — the basis for discovery and hiring.

## WHAT IT DOES
- Manufacturer profiles (business, categories, MOQ + unit, capacity, specialisations, about, notable clients, tier, FabScore).
- Fabric mill / trim supplier / artisan / job worker profiles (type-specific fields).
- FabTalent profiles (Designer/Master/Merchandiser/QC) — portfolio, skill-verified badge, rates, availability, reviews, repeat-hire rate.
- Profiles build automatically from completed gigs/orders.

## STATUS
Manufacturer profile save/discovery ✅ · profile detail tabs 🟡 (Overview real) · mill/trim/artisan/talent profiles 🟡/🔴.

## KEY RULES
Type-adaptive (one skeleton, type-specific flesh). Verified badges only from real assessment. Merit-based visibility.

## CONNECTS TO
Identity/Trust (badges, FabScore) · Discovery · FabMerch · Orders (notable clients from real orders).

## DATA
manufacturer_profiles (live); planned fabtalent_profiles (TAL-), plus mill/trim/artisan/jobworker profile tables.
